Welcome to AuditEngine

Complete these three steps to run your first multi-agent codebase audit.

1Log in

Paste the JWT token issued by your administrator. The token is scoped to a tenant and expires after one hour by default.

Tip: lost your token? Ask an admin to issue a new one for your tenant.
Log in

2Connect a repository

Choose a tenant, then upload a zip, paste files, or provide a public GitHub URL. OAuth can be connected per tenant for private repositories.

Tip: start with a small repo to see the full pipeline quickly.
Start new audit

3Track results

Watch the live dashboard, task board, and findings view while agents analyze files in parallel.

Tip: mark tasks done only after providing the commit SHA that resolves the finding.
View audits
